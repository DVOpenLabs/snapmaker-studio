# Creative input continuity

Source path, explicit format and output folder survive route navigation in app
memory only. Returning does not inspect or prepare automatically. Reports,
material choices and preparation results are not reused: inspect again, review
materials and explicitly prepare. Clear creative inputs resets the draft and
invalidates pending view replies. It does not cancel engine work, delete output
files or clear a printer setup. App restart loses the input draft.

A monotonic shared revision changes on edits, material choices and Clear, so an older component cannot link a written copy after later edits or Clear in a successor view. Navigation alone leaves this revision unchanged and still permits a valid completed copy to link. Invalidated written copies are recorded as unlinked.
