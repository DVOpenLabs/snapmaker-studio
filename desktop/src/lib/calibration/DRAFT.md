# Calibration input continuity

Unsaved input and user-entered observations stay in memory while Studio stays
open, including when visiting another tool. This is one palette calibration
draft, independent of an open print job. No browser/disk persistence and no
automatic evaluation or material mapping. Returning does not silently evaluate.

Changing the palette or basis still clears physical readings. Owned filament
alternatives remain user declarations, not verified inventory or measurements.
Clear calibration inputs resets the form (including empty physical readings),
but deletes no saved comparisons and cannot cancel a request already sent to
the local engine. Old async evaluation/file-import responses remain ignored.
Result panels are not retained across navigation; Compare or saved history
loads them explicitly. Restarting Studio loses this unsaved draft.
